# university-2026-FSE
### Репозиторий для практических заданий по Основам программной ижинерии для ГрГУ


## Lab_02: 
- B1:   Программа расчёта расстояния между локациями на карте. 
    - Программа берёт исходные данные (данные для расчёта, файл для проверки) из файла помещённого в папку с ней используя название введённое с клавиатуры 
    - Проводит расчёт 
    - Создаёт новый текстовый файл (название которого в начале выполнения программы вводится с клавиатуры) с результатом
    - Сравнивает полученный результат с "эталонным" (заранее правильным) ответом и выводит совпадение/несовпадение двух файлов 
- B2: Программа вычисления WC-эффекта и средней скорректированной температуры, основанную на наблюдениях.
     - Программа берёт исходные данные (данные для расчёта, файл для проверки) из файла помещённого в папку с ней используя название введённое с клавиатуры
     - Проводит расчёт
     - Создаёт новый текстовый файл (название которого в начале выполнения программы вводится с клавиатуры) с результатом
     - Сравнивает полученный результат с "эталонным" (заранее правильным) ответом и выводит совпадение/несовпадение двух файлов 
## Lab_03: 
 - Программа-игра "Кот и мышь" 
 - Условие задачи : Кот и мышь перемещаются в замкнутом пространстве в форме прямоугольной
сетки, разделенной на клетки. Каждая клетка помечена парой координат (строка, столбец). Каждый может перемещаться по сетке, но не может покидать сетку. Если кот и мышь одновременно достигают той же ячейки, то кот ловит мышь и игра заканчивается.
